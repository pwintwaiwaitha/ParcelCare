# Frontend

Next.js/TypeScript reporting and triage app. app/ composes role routes and the server API proxy; features/ owns report, case-detail and triage UI; shared/ holds typed API helpers and the design system. Customer/rider screens are mobile first; staff uses a responsive workspace. Run `npm ci` then `npm run dev`; see [setup and deployment](../docs/demo-setup.md). Backend API connection uses server-only API_INTERNAL_URL. No OpenAI credentials are needed for this milestone.
